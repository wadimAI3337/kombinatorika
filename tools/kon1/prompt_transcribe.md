ФОРМАТ ВЫХОДНОГО ФАЙЛА:
- Номер страницы внизу листа НЕ переносить. Колонтитулы не переносить.
- Заголовок части «ТЕСТЫ ДЛЯ 1 РАЗРЯДА» — строкой `[[PART 1]]`; «ТЕСТЫ ДЛЯ КАНДИДАТОВ В МАСТЕРА» — строкой `[[PART 2]]`. Слово «РЕШЕНИЯ» не переносить.

ШАХМАТНАЯ НОТАЦИЯ — САМОЕ ВАЖНОЕ:
- Значки фигур заменяй латиницей: король → K, ферзь → Q, ладья → R, слон → B, конь → N.

- Поля пиши латиницей a1–h8.
- Сохраняй как напечатано: двоеточие для взятия (R:e4), сокращённые пешечные взятия (hg, ba), «...» для хода чёрных (1. ... Ne4+), знаки !, ?, !!, ?!, +, #, оценки +-, -+, =, ±, ∓, ∞. Превращение как в книге (a1Q или a1=Q).

- Курсив/жирный не отмечай — только текст.

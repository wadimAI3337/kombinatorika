# Промпт для расшифровки страниц «Помни о сопернике» (М. Дворецкий)

Использовался для параллельных под-агентов: каждый брал 7 страниц подряд.
Страница заранее порезана на две перекрывающиеся половины (0–53% и
47–100% высоты) — `01_pages.py`.

---

Ты расшифровываешь отсканированные страницы русской шахматной книги
М. Дворецкого «Помни о сопернике!» (том {V}). Книга: вступительные главы
с разобранными примерами, упражнения (только диаграммы с подписями) и
«Ответы» — подробные решения упражнений с вариантами.

РАБОЧАЯ ПАПКА: /Users/vadimsamalo/Documents/kombinatorika/tools/dvor/work/v{V}

ТВОИ СТРАНИЦЫ: {PAGES}

Для каждой страницы NNN:
1. Прочитай инструментом Read `img/pNNNa.png` (верх) и `img/pNNNb.png` (низ).
   Части ПЕРЕКРЫВАЮТСЯ примерно на 6% высоты — не дублируй строки, видные в обеих.
2. Запиши результат инструментом Write в `txt/pNNN.txt`.

ПОРЯДОК ЧТЕНИЯ. Текст в две колонки: сначала вся левая колонка сверху
вниз, потом вся правая. Если на странице нет колонок — просто сверху вниз.
Диаграммы вставляй в поток текста там, где они стоят.

РАЗМЕТКА (каждый маркер — с новой строки):
- Колонтитул (номер страницы, «Часть 1», «ВНИМАНИЕ К ВОЗМОЖНОСТЯМ СОПЕРНИКА Ответы») — НЕ переносить.
- Заголовок главы/раздела (крупный: «ВНИМАНИЕ К ВОЗМОЖНОСТЯМ СОПЕРНИКА», «УПРАЖНЕНИЯ», «Ответы», «Предисловие», «Условные обозначения») — `[[H]] текст`.
- Шапка партии над диаграммой (жирные фамилии + строка с турниром/годом) —
  `[[GAME]] Ходжсон – М.Гуревич | Командное первенство Европы, Хайфа 1989`.
  Звёздочку после фамилии сохраняй (`В.Брон *`). Если строки турнира нет — только фамилии.
- Диаграмма — `[[DIAG 1-5 turn=w]]`:
  * номер слева от доски («1-5», «2-14») — если он есть; нет номера — не пиши;
  * `turn=w`, если слева внизу у доски квадратик со знаком «?» БЕЛЫЙ (контурный);
    `turn=b`, если квадратик ЧЁРНЫЙ (залитый, «?» белым по чёрному); нет квадратика — не пиши;
  * маленькая диаграмма (вдвое меньше обычной) — добавь `small`: `[[DIAG small turn=b]]`.
  Фигуры на доске НЕ расшифровывай — это делается отдельно.
- Подпись курсивом под диаграммой («Стоит ли играть 31...Rfc8 ?», «Оценить 21.Nc4», «Черные сдались») — `[[CAP]] текст`.
- Абзацы разделяй пустой строкой. Переносы слов (дефис в конце строки) склеивай.
  Внутри абзаца строки склеивай в одну.
- Если страница НАЧИНАЕТСЯ с продолжения абзаца с прошлой страницы (первая строка
  без красной строки/отступа) — первой строкой файла поставь `[[CONT]]`.
- ЖИРНЫЕ ходы (жирный шрифт) оборачивай в `**…**`: `После **35.Qh6+! Kg8 36.Re6** черным…`.
  Это важно: жирным выделены главные ходы. Обычные (нежирные) ходы — без звёздочек.
  Курсив не отмечай.

ШАХМАТНАЯ НОТАЦИЯ — САМОЕ ВАЖНОЕ:
- Значки фигур заменяй латиницей: король → K, ферзь → Q, ладья → R, слон → B, конь → N.
  Контурные и залитые значки — одна и та же буква.
- Поля — латиницей a1–h8. Сверяй каждую букву и цифру с картинкой (c/e, b/h, f/t, 3/8, 1/l).
- Сохраняй как напечатано: двоеточие взятия (`Q:e6`, `R:f4`), короткие пешечные
  взятия (`hg`, `fe`, `gf`), «...» для хода чёрных (`23...Qh1+`), рокировку `0-0` / `0-0-0`,
  превращение как в книге (`b8Q`, `b8R`), знаки `! ? !! ?? !? ?!`, `+ #`,
  оценки `+- -+ = ± ∓ ⩲ ⩱ ∞` (± пиши «±», «+–» пиши «+-»).
- Варианты в скобках сохраняй со скобками. Буквенные ветки «А)», «Б)», «а)», «б)» сохраняй.
- Ходы, названные словами («выпад ферзем на a4», «размен на d5»), оставляй как в книге.

ТОЧНОСТЬ ВАЖНЕЕ СКОРОСТИ. Ходы — главная ценность файла.

Когда все файлы записаны, ответь одной-двумя строками: список файлов и номера
упражнений (из `[[DIAG N]]`), встретившиеся на каждой странице.
